# 功能包模板

功能包 ID：`PKG-<层>-<主题>`

文档成熟度：基础草案。需求确认程度与实现/验证状态分别注明。

## 目标与责任层

写清用户目标或服务能力；说明前端、后端、共享契约各负责什么。

## 规范节点

| 节点 | 目的 | 需求/来源 | 依赖 | 验收 |
|---|---|---|---|---|
| 01-...md | 可独立讨论的具体子功能 | REQ / 来源 | 其他节点 / CT | TEST / 待定 |

## 输入与输出边界

索引到唯一主责契约，不复制字段表。

## 已确认与未决

分别列出来源支持的决定、建议和 OQ；未知接口保留待核对。

## 关联与细化顺序

列前后端对应节点、共享组件和关键验收入口。
