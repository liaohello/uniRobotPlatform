# 页面与设计一致性验收

规范 ID：`QA-VISUAL-CONSISTENCY` · 责任层：验收设计 · 版本：V0.3（2026-10-21）

本页是未来原型/产品验收设计，不是已运行的产品测试。文档静态核对另记：页面图片存在性、原件哈希、链接与索引一致性；这些检查不能证明交互或后端正确。

<a id="test-vis-001"></a>
## TEST-VIS-001｜页面参考覆盖

每个 PAGE 节点包含实际存在的主图，资产映射能回到原件/PPT；局部参考明确覆盖范围，不将历史图直接标最终定稿。

状态：产品/原型验收未执行；实际证据待实现后提供。

<a id="test-vis-002"></a>
## TEST-VIS-002｜图片冲突纠偏

检查 SO101 三路 RGB、主臂无相机、关节监控与显式接管；原型不照搬未核实硬件/数据或设计标注。

状态：产品/原型验收未执行；实际证据待实现后提供。

<a id="test-ctx-001"></a>
## TEST-CTX-001｜统一在线执行入口

从模型/评估进入运行时指向同一 Session/Simulation，原页面只读预览；离线预测不向执行器提交动作。

状态：产品/原型验收未执行；实际证据待实现后提供。

<a id="test-ctx-002"></a>
## TEST-CTX-002｜页面对象与时钟

Data/资源/报告页没有含义不明的全局运行播放条；Replay 时钟不会改变 Live；Edit 历史配置创建新草案。

状态：产品/原型验收未执行；实际证据待实现后提供。

<a id="test-model-001"></a>
## TEST-MODEL-001｜模型能力门槛

仅导入或注册的权重无法直接执行；观测、动作、归一化与控制适配未知时显示原因，并阻止运行。

状态：产品/原型验收未执行；实际证据待实现后提供。

<a id="test-train-001"></a>
## TEST-TRAIN-001｜训练草案与作业

提交后作业配置固定，修改进入新草案；未支持 Pause/某 Loss 的适配器不显示虚构能力。

状态：产品/原型验收未执行；实际证据待实现后提供。

<a id="test-eval-002"></a>
## TEST-EVAL-002｜比较证据与统计

协议/任务/环境/测试条件不同会标出差异；缺重复统计不显示无依据 std/CI；表格、图和导出同一报告修订。

状态：产品/原型验收未执行；实际证据待实现后提供。

## TEST-EVAL-003｜自主与辅助分母

接管救回的轨迹保留辅助结果，不能从主自主尝试分母静默剔除；Pending、未知、无效和失败分别计数并说明。

状态：产品/原型验收未执行；实际证据待实现后提供。
