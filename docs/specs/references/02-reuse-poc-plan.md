## PoC 范围与交付

本轮只写计划，不安装依赖、启动服务器、编译场景或运行浏览器。后续执行遵守现有工程的服务器执行约束，不因 PoC 擅自改基线环境。

| PoC | 问题 | 需要的可核对交付 | 不通过时 |
|---|---|---|---|
| Scene Editor | 能否只复用对象摆放并导出受限配置 | 位姿/对象 ID、源模型保持检查、被丢弃/不支持字段说明 | 仅借鉴交互，由自有 Scene Builder 应用配置 |
| Drei | 能否复用手柄且符合选择、Orbit、焦点、取消与 Preview 语义 | Joint/TCP 目标适配、无越权/无自动执行的交互证据 | 保留现有 Three.js 控件，避免为库重写全部渲染 |
| Dockview | 能否保存/恢复 A–H 与任务预设 | 布局版本、缺面板降级、拖动中保护、尺寸与焦点检查 | 先用固定可调整分栏，保持同一面板接口 |

## 共同门

固定来源版本/许可证与依赖；优先复用本地实现；记录输入、实际运行版本和缺陷。浏览器渲染只处理展示，物理/感知/规划留服务器。采用组件不改变控制权、采集/策略观测与原始数据边界。

编辑器 PoC 不能仅凭 XML 能加载就判定模型等价；Gizmo 能拖动不代表 IK 或轨迹可执行；布局能保存不代表状态生命周期正确。通过后才在统一骨架中接入一个真实任务。
