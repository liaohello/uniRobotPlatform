## 已实现的行为与范围

- 固定 `mobilecar.g1.teleop` recipe，草案保存选定内容的版本/清单和执行指纹。只开放名称/描述；初态可写字段为空，未知字段、seed、任意 preset/初态请求返回 422。
- SQLite 保存草案，可列表/读取，服务进程退出后仍可重载。`UNIROBOT_DRAFT_DB` 指定路径，默认 `backend/var/drafts.sqlite3`，属于本机运行状态，不进入 Git；没有第二套 native Recorder 或逐帧数据保存。
- 保存用 `base_revision` 乐观并发检查；同草案另一宿主已保存则返回 409，保留先接受的内容。界面保留冲突输入，用户明确放弃并重载后才取新修订。
- 名称/描述变化增加 `draft_revision`，不增加 `execution_revision` 或改变执行 fingerprint；没有内容变化的保存不增加修订。持久化验证回执不作为用户配置编辑递增修订。
- 校验使用已保存的 execution revision/fingerprint。四个 native GET 仅提供已声明范围的只读证据；必需 Session 绑定 unsupported、完整内容 not_checked，因此总体 failed、validated_snapshot_id=null。metadata 在检查期间保存会被保留；过期依赖的迟到结果返回 409，不覆盖当前草案。
- 固定依赖发生变化后，观察到的 stale 状态持久保存；改回不自动恢复验证。当前切片通过新建草案采用新固定预设，不提供任意依赖编辑/迁移。
- UI 草案状态与接入诊断各自按挂载实例注入服务，无共享可写草案 store。Session/Start 按钮禁用，绕过按钮直接调用 Session 创建也返回 unsupported。

源码：[DraftStore / 请求模型](../backend/src/unirobot/drafts.py)、[API](../backend/src/unirobot/api.py)、[宿主注入的草案编辑器](../backend/src/unirobot/static/mobilecar/drafts.js)、[测试](../backend/tests/test_drafts.py)。

## 当前 HTTP 契约

| 方法 / 路径 | 请求 / 结果 |
|---|---|
| POST `/api/v1/experiment-drafts` | preset_id 固定 G1，name/description；201，返回 draft_id、draft_revision、execution_revision、fingerprint、固定 preset、validation、时间 |
| GET `/api/v1/experiment-drafts` | 已保存草案列表 |
| GET `/api/v1/experiment-drafts/{id}` | 完整草案；不存在返回 404 |
| PUT `/api/v1/experiment-drafts/{id}` | base_revision + name/description 的完整元数据替换；成功返回当前草案，旧修订返回 409 |
| POST `/api/v1/experiment-drafts/{id}/validate` | execution_revision + fingerprint；回执附 validation_id、检查项和适用修订；当前总体 failed，无执行快照；过期请求 409 |
| POST `/api/v1/sessions` | 请求含 validated_snapshot_id、execution_revision、fingerprint、idempotency_key；当前一律 409/code=unsupported，不创建 Session |

输入使用既有 Contract 的 extra=forbid，错误明确到字段/原因；固定 preset 内容保存在草案中，不通过保存名称/描述修改或自动跟随新 preset。draftRevision 与执行状态由后端管理。
